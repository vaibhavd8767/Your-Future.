# 🎓 College Portal

A modern and beginner-friendly **College Portal Web Application** developed using **React, TypeScript, Vite, and Tailwind CSS**.

The main purpose of this project is to help students **search, explore, filter, and save college information** in one place. It also provides an **Admin Dashboard** for managing college records.

## 🚀 Features

### 👨‍🎓 Student

* 🔐 Student Login
* 🔎 Search colleges
* 🎯 Filter by State, District, Branch and Fees
* 📊 Sort college results
* 🏫 View college details
* ❤️ Save colleges
* 👤 Manage profile
* 📚 View saved colleges

### 👨‍💼 Admin

* 🔐 Admin Login
* ➕ Add colleges
* ✏️ Edit college information
* 🗑️ Delete colleges
* 📋 Manage college records

### 🎨 UI

* Responsive design
* Modern user interface
* Tailwind CSS styling
* Interactive 3D background
* Fast Vite development

## 💻 How to Run

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd college
```

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## 🗄️ Database

The project includes optional **PHP and MySQL** support through XAMPP.

```text
public/api.php
public/database.sql
```

The database can be connected for permanent storage of college records.
